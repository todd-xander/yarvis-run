# Yarvis Run

Content-driven site built with [Next.js](https://nextjs.org/).

## Development

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

Build the app:

```bash
npm run build
```

Start the production server locally:

```bash
npm run start
```

## Deployment

This project is configured as a standard Next.js app and can be deployed directly to [Vercel](https://vercel.com/).
